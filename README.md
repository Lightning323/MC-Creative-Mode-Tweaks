# MC-Creative Mode Tweaks
[![Custom Badge](https://img.shields.io/badge/Download-CurseForge-orange?style=for-the-badge&logo=curseforge)](https://www.curseforge.com/minecraft/mc-mods/creative-mode-tweaks)

Improves the Creative Mode experience by adding subtle enhancements and quality-of-life features. Every feature is designed to blend in with the vanilla experience and is highly configurable, allowing players to fine-tune settings to their preference via a config file.

## Current Features
-  Noclip Mode – Move seamlessly through blocks while in Creative Mode.
-  Extended Reach Distance – Interact with blocks and entities from much farther away.
-  Replace Tool – Instantly swap blocks without breaking and placing them manually.
-  Disabled Flight Inertia – Fly with precision, eliminating the momentum delay when stopping.


## Hotbar overhaul
This mod changes how the hotbar works in creative mode to prevent the issues that arise with only 9 slots for quick access:

### problem: It is very easy to let the hotbars fill up with items that are not used often.
   2. SOLUTION: Expand the hotbar to easily select and see all 4 slots
      - if enough room is available, hotbar will be 16 slots wide instead of 9
      - you can "scroll" across the hotbar like in tessera (it wraps around)
   3. Whatever "slot" the player is on when we open the creative menu is what we see in the inventory screen
   4. switch between slots with arrow keys in inventory or hotbar (scrolling in inventory lets you switch hotbars) (When holding the key, we see all slots)

### problem: There is no easy way to ditch unused items
   4. SOLUTION: Q doesnt drop the item, it erases it entirely (Or set a diff keybind)
