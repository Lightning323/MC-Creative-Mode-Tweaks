# MC-Creative Mode Tweaks

[![Custom Badge](https://img.shields.io/badge/Download-CurseForge-orange?style=for-the-badge&logo=curseforge)](https://www.curseforge.com/minecraft/mc-mods/creative-mode-tweaks)
[![Custom Badge](https://img.shields.io/badge/Download-Modrinth-green?style=for-the-badge&logo=modrinth)](https://modrinth.com/mod/creative-mode-tweaks)

**Improves the Creative Mode experience by adding subtle enhancements and quality-of-life features.**

Every feature is designed to blend in with the vanilla experience and is highly configurable, allowing players to fine-tune settings to their preference via a config file.

# Features
-  Building tools! Build multi-block structures effortlessly in creative or optionally, survival as well.
-  Noclip Mode – Move seamlessly through blocks while in Creative Mode.
-  Extended Reach Distance – Interact with blocks and entities from much farther away.
-  Disabled Flight Inertia – Fly with precision, eliminating the momentum delay when stopping.
-  Night vision mode
-  Hotbar enhancements
